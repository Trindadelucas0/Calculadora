

# 🧮 Calculadora Web - Projeto Simples e Funcional

Este projeto é uma **calculadora online**, criada com HTML, CSS e JavaScript. A ideia é oferecer uma ferramenta prática, bonita e responsiva para realizar operações matemáticas básicas diretamente no navegador.

👉 [Clique aqui para acessar a calculadora](https://trindadelucas0.github.io/Calculadora/)

---

## ✨ Características

- ✅ Interface limpa e responsiva
- 🧠 Realiza operações de soma, subtração, multiplicação e divisão
- 📱 Compatível com dispositivos móveis
- ⚙️ Fácil de personalizar e expandir funcionalidades

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (com Flexbox)
- JavaScript puro
